# Checkpoint: Step 7 终审校验

> **审查级别**：L2（深度审查）— 需由独立 subagent 验证全链路产出。
> **审查原则**：你是最终审查者，交付前必须确认所有 high 级别项经得起质疑。

## 校验清单

### 事实源真实性
- [ ] 随机抽样 ≥ 30%（最少 10 条），逐条核对源文件行号与代码片段
- [ ] 假阳性率 ≤ 10%（超过则全量复核）

### 分级最终确认
- [ ] 所有 high 项已确认影响面评估准确
- [ ] 无应升未升（medium 实际应为 high）
- [ ] 无应降未降（low 被误标为 high）

### 方案完整性
- [ ] 所有 high 项有 before/after 代码 + ≥ 3 个单测 case
- [ ] 所有 medium 项有 before/after 代码 + 1-2 个单测 case
- [ ] 方案不引入新问题（如批量查询 OOM、抽取后循环依赖）

### 覆盖完整性
- [ ] 扫描覆盖了 Step 1 确认的全部模块
- [ ] 排除目录被正确排除
- [ ] 入口层清单无遗漏模块

## 判定标准

- **全部 ✅**：进入 Step 8 报告生成
- **存在 ❌**：修正后重新校验，最多重试 2 次
- **仅 ⚠️**：标注后进入 Step 8
