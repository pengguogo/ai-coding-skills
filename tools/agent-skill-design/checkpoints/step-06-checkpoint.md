# Checkpoint: Step 6 组装完成校验

> **审查级别**：L2（深度审查）— 需验证所有产出文件完整性和一致性。
> **审查原则**：你是审查者，验证目标技能的所有文件是否齐全、内容是否自洽。

## 校验清单

### 文件完整性检查
- [ ] SKILL.md 已生成且 frontmatter 完整（name + description）
- [ ] 每个 Phase 引用的 Step 文件均存在
- [ ] 每个 subagent 步骤对应的 agents/*.md 存在
- [ ] 每个校验点对应的 checkpoints/*.md 存在
- [ ] references 中引用的模板文件均存在

### 内容一致性检查
- [ ] 触发词与 Step 1 需求澄清一致
- [ ] 交付物命名规则与 Step 1 输出契约一致
- [ ] 执行原则与 Step 1 关键约束一致
- [ ] 责任矩阵与 Step 3 执行模式分配一致
- [ ] Phases/Steps 清单与 Step 2 划分方案一致

### 可用性检查
- [ ] description 字段包含功能说明 + 触发条件
- [ ] 触发词覆盖用户常见表达方式
- [ ] 每个 Step 文件的 input/output 与实际数据流一致
- [ ] 步骤间不存在悬空引用（引用了不存在的前置步骤产出）

### 模板可用性检查
- [ ] 产出模板文件可直接打开/渲染（如 HTML 可在浏览器打开）
- [ ] 占位符命名统一（使用 `{KEY_NAME}` 格式）
- [ ] 占位符有对应的填充来源说明

## 判定标准

- **全部 ✅**：技能设计完成，可投入使用
- **存在 ❌**：修正对应文件后重新校验
- **仅 ⚠️**：标注为 `[建议优化]` 后交付
