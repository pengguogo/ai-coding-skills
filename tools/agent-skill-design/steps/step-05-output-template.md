# Step 5: 产出模板设计

## 元信息

- execution-mode: inline

## 参数

- input: Step 1-4 的完整产出（需求 + 步骤划分 + 代理设计 + 质量机制）
- output: 产出物模板文件

## 执行指令

### 1. 确定产出物形态

根据技能输出类型，选择模板形态：

| 输出类型 | 模板格式 | 示例 |
|----------|----------|------|
| HTML 报告 | 完整 HTML 文件（含 CSS + 结构骨架） | `report-template.html` |
| Markdown 文档 | Markdown 模板（含章节骨架 + 占位符） | `doc-template.md` |
| 代码文件 | 代码骨架（含注释标注的插入点） | `code-template.{ext}` |
| JSON/YAML 配置 | 结构化配置文件（含 Schema 注释） | `config-template.json` |
| Excel 表格 | 表格结构定义（列名 + 格式规则） | `table-template.xlsx` 或结构说明 |

### 2. 设计模板结构

对模板进行结构化设计：

**HTML 模板**：
- 完整 `<html>` 文档骨架
- 内联 CSS 样式定义（按元素类型：表头/数据行/标签/注释块/分隔线）
- 章节骨架（标题 + 表格/代码块占位符 + 示例数据）
- 占位符统一使用 `{KEY_NAME}` 格式

**Markdown 模板**：
- 章节骨架（标题 + 表格结构 + 代码块占位）
- 占位符使用 `{KEY_NAME}` 格式

### 3. 标注占位符

在模板中清晰标注每个插入点：

```html
<!-- PLACEHOLDER: {TITLE} → 报告主标题，如 "XX影响分析报告" -->
<h1>{TITLE}</h1>

<!-- PLACEHOLDER: {TABLE_ROWS} → 表格数据行，由 Step N 产出填充 -->
<tbody>{TABLE_ROWS}</tbody>
```

每个占位符需要说明：
- **来源**：由哪个 Step 的产出填充
- **格式**：期望的数据格式（文本/HTML/结构化对象）
- **示例值**：便于理解

### 4. 验证模板完整性

- 确认模板覆盖了所有步骤的产出
- 确认模板与 SKILL.md 中「交付物」定义的产出物一致
- 确认模板中无多余或遗漏的占位符

### 5. 输出模板文件 + 映射表

```
## 产出模板

### 模板文件列表

| 文件 | 用途 | 填充步骤 |
|------|------|----------|
| references/{file-name} | {用途} | Step N → {占位符} |

### 占位符映射表

| 占位符 | 数据来源 | 格式 | 示例值 |
|--------|----------|------|--------|
| {KEY1} | Step N 产出 | text | "XX分析报告" |
| {KEY2} | Step M 产出 | HTML | "<tr>...</tr>" |
```

## 产出

- 产出模板文件（references/*）
- 占位符映射表
