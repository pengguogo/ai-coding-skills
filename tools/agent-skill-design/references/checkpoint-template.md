# Checkpoint 模板

> 复制此模板为 `step-0N-checkpoint.md`，用于质量校验点的审查清单。

---

```
# Checkpoint: Step {N} {校验名称}

> **审查级别**：{L1 轻量 / L2 深度 / L3 全量}
> **审查原则**：{一句话说明审查立场}

## 校验清单

### {维度1}检查
- [ ] {检查项1}
- [ ] {检查项2}

### {维度2}检查
- [ ] {检查项3}
- [ ] {检查项4}

### {维度3}检查
- [ ] {检查项5}
- [ ] {检查项6}

## 判定标准

- **全部 ✅**：校验通过，进入下一步
- **存在 ❌**：回到对应步骤修正，最多重试 {N} 次
- **仅 ⚠️**：补充后进入下一步
```

---

## 审查级别说明

| 级别 | 含义 | 适用场景 |
|------|------|----------|
| L1 轻量 | 仅检查产出格式、必填字段 | 格式转换类步骤 |
| L2 深度 | 需验证事实源真实性 | 数据/代码分析类步骤 |
| L3 全量 | 需做全量回归验证 | 最终输出前的终审 |
