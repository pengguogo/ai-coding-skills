# Step 4: 用例详情分析

## 元信息

- execution-mode: subagent
- agent: use-case-detail-analyzer
- input: Step 2 的用例清单 + Step 1 的代码扫描基线 + Step 3 的数据模型
- output: 每个用例的完整详情（规约 + 时序 + 数据关联 + 关联功能）

## 执行指令

### 1. 逐用例提取用例规约

对每个用例，从代码中提取以下信息：

| 字段 | 说明 | 来源 |
|------|------|------|
| 参与者 | 谁发起/参与 | 调用链分析 |
| 接口 | ServiceCode 或 API 入口 | 代码常量/注解 |
| 前置条件 | 执行前的系统状态 | 代码逻辑推断 |
| 后置条件 | 执行后的系统状态 | 返回值/副作用 |
| 主成功流程 | 正常路径步骤（1-5步） | 核心方法流程 |
| 异常流程 | 超时/失败处理 | 异常处理逻辑 |
| 备选流程 | 条件分支路径 | if/switch 逻辑 |
| 业务规则 | 关键规则编号 R1/R2... | 校验/判断逻辑 |

规约格式参照 `references/flow-template.html` 中的 `.uc` 结构。

### 2. 绘制应用间时序图

用 Mermaid `sequenceDiagram` 绘制：

- `participant` 标注应用缩写和全称
- `autonumber` 自动编号
- `Note` 标注关键信息流决策点
- `alt/else` 标注分支流程
- 箭头 `->>` 标注报文/调用方向

参与者命名规则：
```
participant SRC as 发起方<br/>功能描述
participant GW as 编排/网关<br/>中转职责
participant TARGET as 目标系统<br/>职责
```

在时序图内关键落库/出账节点用 `Note` 直接标注信息流/资金流，使图上可见（与下方"信息流/资金流"表呼应）：
```
Note over ACB: 【信息流】账户/协议/利率/还款计划落库
Note over DRW,CL: 【资金流】向付款账户划款出账，记 BAL/OSL
```
标题统一为 `应用间时序（信息流 / 资金流）`。

### 3. 分析信息流/资金流

对每个用例判断：

| 类型 | 判断条件 |
|------|----------|
| 信息流 | 有数据/指令在系统间传递 |
| 资金流 | 涉及金额变动/账户操作 |

格式：
```
| 类型 | 说明 |
|------|------|
| 信息流 | {描述} |
| 资金流 | {描述或"无"} |
```

### 4. 串联数据模型

列出用例涉及的实体及其读/写模式：

```
| 数据模型(表) | 所在应用 | 访问 | 说明 |
|-------------|----------|------|------|
| cif_client | CORE | 写 | 创建客户主档... |
```

### 5. 识别关联功能（应用内实现）

为每个用例识别其背后的**应用内实现单元**（承载类/流程 + 所属应用 + 分层链概要），作为 Step 7 生成 code 时序图的输入。同一实现单元被多个用例复用时只记一次（多对多）。

```
| code 功能单元 | 应用 | 承载类/入口 | 分层链概要 |
|--------------|------|------------|-----------|
| 贷款开立流程编排与落库 | core-service | OpenFlowClImpl.process | Svc→Stria→Micro→Event→DB |
```

Step 6 生成 flow 页时，"关联功能时序图（应用内）"区块先留占位；Step 7 生成 code 时序图后回填真实链接：

```
<a href="../../../code/{app}/{class}/{功能}_sequence.html">{app} · {功能} &#8594;</a>
```

若确无应用内实现可沉淀（如纯外部系统），标注"无关联功能时序图"。

### 6. 输出格式

```
## 用例详情

### UC-{CODE}-01 {用例名}

**用例规约**：
| 字段 | 值 |
|------|-----|
| 参与者 | ... |
...

**应用间时序图**：
sequenceDiagram
    ...

**信息流/资金流**：
| 类型 | 说明 |
|------|------|

**数据模型串联**：
| 数据模型 | 所在应用 | 访问 | 说明 |
|----------|----------|------|------|

**关联功能时序图**：
- [链接]
```
