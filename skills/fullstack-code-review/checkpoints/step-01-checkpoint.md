# Checkpoint: Step 1 终审上下文收集

> **审查级别**：L1（轻量审查）— 只检查结构和内容维度。
> **审查原则**：你是审查者，不是作者。必须重新打开产出文件逐项核对，不能凭记忆判断。

## 审查时需打开的文件
- 产出文件：`{WORKSPACE}/review/01-review-context.md`
- 上游比对：`{TASK}/task-split.md`
- 上游比对：`{WORKSPACE}/review/review-log.md`（若存在）

## 结构检查
- [ ] 包含章节：变更范围概览
- [ ] 包含章节：后端模块清单（表格形式）
- [ ] 包含章节：前端功能点清单（表格形式）
- [ ] 包含章节：小节评审覆盖度摘要
- [ ] 包含章节：待全局确认清单
- [ ] 包含章节：任务完整性对比

## 内容检查
- [ ] 后端模块清单至少有 1 行数据
- [ ] 后端模块清单每行包含：序号、模块名、task-split 编号、变更文件数、小节评审状态、检查策略（6 列）
- [ ] 前端功能点清单至少有 1 行数据（若 task-split 包含前端任务）
- [ ] 小节评审状态为 ✅ 已通过 / ⚠️ 有遗留 / ❌ 未评审 之一
- [ ] 检查策略为 supplement / recheck / full 之一
- [ ] 检查策略与小节评审状态匹配：已通过→supplement，有遗留→recheck，未评审→full
- [ ] task-split 中的所有后端主分类在后端模块清单中均有对应行
- [ ] task-split 中的所有前端功能点在前端功能点清单中均有对应行
- [ ] 若 review-log.md 存在，待全局确认清单与 review-log.md 顶部清单一致

## 抽查校验检查（强制）
- [ ] 产出文件中包含"抽查校验"小节或等价记录
- [ ] 至少抽查了 1 个小节评审状态为 ✅ 已通过 的模块（若存在已通过的小节）
- [ ] 抽查记录包含：被抽查小节名称、抽查的发现表格行数、摘要声称的发现数、是否一致
- [ ] 若抽查发现摘要数据与发现行数不一致，该模块的检查策略已降级为 `full`（而非 `supplement`）
- [ ] 若所有模块均为 ❌ 未评审，标注"无已通过小节可抽查"即可

## 待确认项提取
- 任务完整性对比中状态为 ❌ 未实现 或 ⚠️ 部分实现 的任务
- 小节评审覆盖度摘要中"未评审"数量 > 0 时标注原因
- 产出正文中所有 `[无小节评审记录]` 标记
