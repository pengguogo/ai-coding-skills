## 3. 前端任务拆分原则与粒度约定

- 适中粒度：每个任务聚焦一个可独立验证的模块/组件功能点
- 单一职责：每个任务完成一个明确功能点
- 可测试：每个任务完成后具备可验证的验收要点
- 与 **`frontend-web.md`** 一致（PC Web 分端设计文件，经 `frontend-design.md` 入口定位）
