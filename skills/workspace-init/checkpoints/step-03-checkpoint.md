# Checkpoint: Step 3 校验与修复

> **审查级别**：L1（轻量审查）— 只检查结构和内容维度。
> **审查原则**：确认每一有效数据行都已执行完整的 5 项校验，自动修复仅在安全范围内执行，未通过的条目有可操作的手动清单。必须重新打开产出文件逐项核对，不能凭记忆判断。

## 审查时需打开的文件
- 审查对象：控制台输出中的校验结果和手动清单
- 上游比对：`repos.txt`（对照行数）

## 结构检查
- [ ] 每一有效数据行都已执行 5 项校验（目录存在、是 git 仓库、远端 URL、当前分支、与远端同步）
- [ ] 汇总数字正确（通过 + 已修复 + 失败 = 有效行总数）

## 内容检查
- [ ] 自动修复仅在安全范围内执行（无 reset --hard、无删除目录、无自动 merge、无写入 token）
- [ ] 未通过且无法自动修复的条目已生成手动清单
- [ ] 手动清单中每条包含：name、url、branch、失败原因、可复制的 git 命令
- [ ] 最终汇总已输出（通过 N / 已修复 N / 失败 N）

## 待确认项提取
- 若有失败条目 → 提取手动清单为待用户处理项
