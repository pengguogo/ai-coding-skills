# Checkpoint: Step 5 质量校验

> **审查级别**：L2（深度审查）— 需验证事实源真实性。
> **审查原则**：你是审查者，不是作者。必须实际读取代码文件验证，不能凭记忆判断。

## 校验清单

### 完整性检查
- [ ] 每个被修改的字段都有对应的后置功能分析
- [ ] 未遗漏关键的 EOD Job（搜索 `*Eod*`、`*Batch*` 相关 Mapper）
- [ ] 未遗漏关键的在线交易引用

### 事实源验证
- [ ] 引用的代码文件路径真实存在（readFile 确认）
- [ ] 引用行号处的代码内容与描述一致
- [ ] Mapper XML 中的 SQL 条件与报告描述一致

### 逻辑一致性
- [ ] P0 风险确实涉及资金/出单层面问题
- [ ] P1 风险确实涉及期次/凭证/日期偏移
- [ ] 风险等级与影响说明匹配

### WHERE 条件安全性
- [ ] 每条 SQL 的 WHERE 条件不会误伤非目标记录
- [ ] 可能匹配多条记录的情况已标注为风险点

### 时序依赖
- [ ] 多条 SQL 间的执行顺序依赖已识别
- [ ] 不存在因顺序错误导致结果不一致的隐患

## 判定标准

- **全部 ✅**：校验通过，进入 Step 6
- **存在 ❌**：回到对应 Step 修正，最多重试 2 次
- **仅 ⚠️**：补充后进入 Step 6
