# 更新日志

本页面记录 AI Coding Skills 的版本变更。

---

## v1.0.0 (2026-06-10)

### 新增

- 🎉 初始版本发布
- 包含 12 个 Skills，覆盖 8 个流水线阶段
- 支持 Cursor / Kiro / Trae / Claude Code / OpenCode

### 技能列表

| 阶段 | Skill | 说明 |
|------|-------|------|
| 0 | `spec-skills-refresh` | 技能分发与同步 |
| 1 | `workspace-init` | 环境初始化 |
| 2 | `code-knowledge-init` | 代码知识还原 |
| 2 | `application-knowledge-init` | 应用架构知识 |
| 2 | `business-knowledge-init` | 业务架构知识 |
| 3 | `prototype-derivation` | 原型推导 |
| 3 | `requirement-analysis` | 需求分析 |
| 4 | `fullstack-design` | 技术方案设计 |
| 5 | `task-split` | 任务拆分 |
| 6 | `fullstack-code-implementation` | 代码实现 |
| 7 | `fullstack-code-review` | 代码审查 |
| 7 | `project-archive` | 项目归档 |

### 流水线阶段

1. **阶段 0** — 技能分发与同步
2. **阶段 1** — 环境初始化
3. **阶段 2** — 知识还原（代码 → 应用 → 业务）
4. **阶段 3** — 需求分析（原型推导 → 需求结构化）
5. **阶段 4** — 技术方案设计（后端 → 前端）
6. **阶段 5** — 任务拆分
7. **阶段 6** — 代码实现
8. **阶段 7** — 代码审查与归档

## 版本说明

- **Major**（主版本）：不兼容的变更
- **Minor**（次版本）：向后兼容的新功能
- **Patch**（补丁版本）：向后兼容的 bug 修复
